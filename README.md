# VRILZ Key System

Cloudflare Worker + Cloudflare D1 key system.

## Features

- Free key claim
- 24 hour claim cooldown
- 10 minute redeem window
- 24 hour free key duration
- Premium key generation
- Premium custom duration
- Key revoke
- Key deletion
- D1 database
- GitHub deployment

## Admin

Admin token is stored as a Cloudflare Worker secret.

Never put the admin token inside GitHub source code.
