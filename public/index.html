Cara Membuat & Memakai Key

How to create & use your key
  1. Buka bagian Create Key.
  2. Masukkan username kamu.
  3. Klik CREATE KEY dan tunggu sampai key muncul.
  4. Klik COPY KEY.
  5. Buka VRILZ Lua Script lalu paste key pada Key System.
EN: Enter your username → Generate → Copy → Paste into the Lua Script. Key validation is handled by the script.
