Cara Membuat & Memakai Key

How to create & use your key
  1. Buka bagian Create Key.
  2. Klik Create Key dan tunggu sampai key muncul.
  3. Klik Copy Key.
  4. Buka VRILZ Lua Script dan masukkan key pada kolom Key System.
  5. Jalankan script. Validasi key dilakukan oleh script.
EN: Generate → Copy → Paste into the Lua script → Run. This website does not validate the key.

Cara Order Key Premium

How to order a Premium Key

EN: Choose a plan → join Discord → contact staff → follow payment instructions → receive your Premium access.
